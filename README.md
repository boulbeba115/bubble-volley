# Bubble Volley — Beach Cup

A 3D arcade beach-volleyball game with jelly blobs, built with three.js and Blender-made models.

**Play it:** https://boulbeba115.github.io/bubble-volley/

## Controls

| | Move | Jump | Dash | Bump (set) |
|---|---|---|---|---|
| Player 1 | `A` / `D` | `W` or `Space` | `S` or `Shift` | `E` or `F` |
| Player 2 | `←` / `→` | `↑` | `↓` | `Enter` or right `Shift` |

`Esc` pauses. When you are the only local player (vs CPU, Beach Cup, online) the arrow keys work too. Touch buttons appear on phones.

## How it plays

- Land the ball on the other side to score. Each side gets **3 touches**; a 4th gives away the point.
- **Bump** just before the ball arrives to pop it straight up, then **jump into it to spike**. In the air, hold toward the net for a power spike or away from it for a drop shot.
- Every touch charges your **super meter**. When your blob glows, jump into the ball for a flaming **super spike**.
- Pop the floating **bubbles** with the ball for power-ups: jumbo size, turbo, sticky rival, moon ball, instant super.

## Modes

- **1 Player** — against the CPU (easy / medium / hard).
- **Beach Cup** — beat Sandy (the wall), Coral (the diver) and Tsunami (the spiker) in a row to win the trophy.
- **2 Players** — on one keyboard.
- **Play Online** — one player creates a room and shares the 4-letter code (or the invite link); the other joins.
- **Styles** — Classic, Chaos (power-ups everywhere), Low Gravity, Giant Ball, Party (a new random rule every two points).

Matches are win-by-two (deuce), a player trailing by 3+ charges their super meter faster, and two blob colours are unlocked by a 15-touch rally and by winning the Beach Cup.

### About online play

Online matches are peer-to-peer (WebRTC via [PeerJS](https://peerjs.com)). The free public PeerJS broker is only used
to introduce the two browsers; the game itself runs on the host's machine and streams to the guest. There is no game
server, so it works from a static site — but very strict networks/firewalls can block the direct connection.

## Develop

```
npm install
npm run dev      # live-reload dev server
npm run build    # builds dist/index.html (one self-contained file — double-click to play offline)
npm run assets   # regenerates the GLB models with Blender (needs `blender` on PATH)
npm run sim      # headless CPU-vs-CPU balance check
node tools/nettest.mjs   # two-browser end-to-end test of online play (needs Edge)
```

Pushing to `main` builds and deploys to GitHub Pages (`.github/workflows/deploy.yml`).

## Layout

```
tools/build_assets.py   Blender script that models the blobs, ball and beach
src/assets/models/      generated .glb files
src/config.js           physics constants, difficulty levels, styles, cup rivals, arena palettes
src/game/               physics.js (simulation), ai.js (CPU), match.js (rules + stats)
src/net/                net.js (room codes + WebRTC), netmatch.js (snapshots + guest-side prediction)
src/render/             stage.js (scene, sky, ocean, camera, critters), actors.js (blobs, ball, bubbles), fx.js (particles)
src/audio/audio.js      synthesised sound effects and music (WebAudio)
src/ui/                 menus, HUD, styles
src/main.js             game states and main loop
bubble-volley.html      the original 2D prototype, kept for reference
```
